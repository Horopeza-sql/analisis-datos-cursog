# 🗺️ Roadmap del Programa Completo

Esta es la ruta paso a paso que recorrerás en cada fase para dominar el ecosistema de análisis de datos.

---

## 🛠️ Las 5 Fases del Aprendizaje

### 1️⃣ Fase 1: SQL para Análisis de Datos
- Fundamentos de bases de datos relacionales (MySQL).
- Consultas esenciales (`SELECT`, `WHERE`, `ORDER BY`, `LIMIT`).
- Agregaciones y preguntas de negocio (`GROUP BY`, `HAVING`).
- Relaciones y combinación de tablas (`JOINs`).
- SQL avanzado (Subconsultas, CTEs y Window Functions).

### 2️⃣ Fase 2: Python para Análisis de Datos
- Variables, estructuras y lógica básica.
- Manipulación de dataframes con `pandas` y `numpy`.
- Limpieza y tratamiento de datos faltantes.

### 3️⃣ Fase 3: R para Análisis de Datos
- Estadística descriptiva e inferencial.
- Análisis exploratorio de datos (EDA).

### 4️⃣ Fase 4: Power BI y Tableau
- Conexión de fuentes de datos.
- Creación de KPIs, medidas y métricas.
- Diseño de cuadros de mando e historias de datos.

### 5️⃣ Fase 5: Proyecto Integrador Final
- Conexión del flujo completo (SQL → Python/R → Power BI).
- Publicación del portafolio profesional documentado en GitHub.
